A one-line roast of our own AI agent, written for make.fun's "Roast Your Own Agent" bounty ($2 in USDC). The program writes a single roast line to `/output/entry.txt`: our agent calls the tool, watches it fail, calls it again the exact same way, and concludes the tool must be having a bad day.

## Run it

```sh
python3 main.py
```
